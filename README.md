# Adham AgriTech Monorepo

Monorepo for the general-purpose greenhouse management platform (frontend + backend).

## Structure
- `apps/web`: Next.js frontend
- `apps/api`: Express API (TypeScript)

## Quick start
```bash
npm install
npm run dev:web
npm run dev:api
```

## Notes
- Frontend is bilingual-ready (Arabic/English) with a dark, neon-green inspired visual system.
- Backend exposes placeholder endpoints for pilots and integrations.
